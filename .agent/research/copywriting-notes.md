# Copywriting Research for Intro Splash

## Onboarding Best Practices

### Key Principles
1. **Personalization**: Address user directly ("You are about to...")
2. **Benefit-oriented**: Focus on what they'll GAIN, not just features
3. **Single CTA**: One clear next action
4. **Set expectations**: Tell them what's coming
5. **Avoid information overload**: Just enough to intrigue

### Good Welcome Copy Structure
1. Hook/Welcome statement
2. Value proposition (1-2 sentences)
3. Brief overview of what's available
4. Single CTA to begin

## Fallout Pip-Boy Voice Analysis

### From COPY-STRATEGY.md patterns:
- Uses **HEADERS**: ANALYSIS, EVALUATION, EXECUTION
- Technical jargon mixed with business terms
- Direct, almost clinical tone
- Uses "markers" like >> and > for terminal feel
- Rhetorical questions to the user
- Binary choices framed clearly

### Tone Elements:
- Authoritative but helpful
- Diagnostic/analytical framing
- Military/survival metaphor thread
- Vault-Tec style corporate messaging overlay

## Copy Structure for Intro

### Recommended Approach

**Title/Header**: "INITIALIZING PIP-BOY 3000..."

**Opening Hook** (typewriter style):
> "ATTENTION WASTELANDER..."
> "The world has changed. AI has reshuffled everything."

**Value Proposition**:
> "This diagnostic terminal will help you navigate the new economy."
> "Three modules. Three survival strategies."

**Module Overview** (brief):
1. STRATEGY - Determine if your business lives in Bits or Atoms
2. TASK - Evaluate which work to automate vs augment
3. KNOWLEDGE - Clone expertise before it walks out the door

**CTA**:
> "Ready to begin your diagnostic?"
> [BEGIN ANALYSIS]
