# YouTube Visual Production Cheatsheet
**AI Assistant Guide for Educational Video Aesthetics & Production**

---

## PART 1: THUMBNAIL DESIGN

### Specifications
- **Size:** 1920 x 1080 pixels (16:9 aspect ratio)
- **File Size:** Max 2MB
- **Format:** JPG, GIF, or PNG
- **Must look clean on mobile** (70% of views are mobile)

### Design Principles

1. **Faces with Emotion**
   - Human faces drive higher engagement
   - Show genuine emotion related to content
   - Eyes should be visible and expressive

2. **Visual Hierarchy**
   - Largest element = most important message
   - Guide eye flow: Face → Text → Supporting element
   - Use contrast to draw attention

3. **Text Usage**
   - Maximum 3-5 words
   - Large, bold, sans-serif fonts (think billboard)
   - High contrast against background
   - Never place text where it competes with face

4. **Color Strategy**
   - Bold, vibrant colors that pop
   - Complementary color combinations
   - Consistent palette across channel for recognition
   - Test: Does it stand out at 1-inch size?

### Thumbnail Formulas That Work

```
TRANSFORMATION    Before/After comparison (split screen)
MYSTERY           Obscured element + question mark/text
REACTION          Face showing strong emotion + result
COMPARISON        Side-by-side with "vs" or "or"
NUMBERED LIST     Large number + hook text (e.g., "7 MISTAKES")
CONTRADICTION     Traditional vs unexpected approach
```

### Thumbnail Checklist
- [ ] Readable at 1-inch size on mobile
- [ ] Face/emotion visible and clear
- [ ] Text is 3-5 words maximum
- [ ] High contrast between elements
- [ ] Matches video content (no clickbait)
- [ ] Consistent with channel branding
- [ ] Tested against your other thumbnails

## PART 2: B-ROLL STRATEGY

### What B-Roll Does
- Visualizes what the speaker is explaining
- Covers cuts in main footage (jump cut concealment)
- Adds visual variety to maintain engagement
- Makes abstract concepts concrete

### Timing Rules
- **Clip Length:** 2-5 seconds per shot
- **Visual Change:** Every 5-10 seconds minimum
- **Longer Segments:** Add B-roll, text overlays, or zooms every 5 seconds

### B-Roll Types for Educational Content

```
TYPE            USE CASE                           EXAMPLE
─────────────────────────────────────────────────────────────────
DEMONSTRATION   Show the action/process            Screen recording,
                                                   hands doing task

METAPHOR        Visualize abstract concepts        Chess for "strategy",
                                                   puzzle for "problem"

DATA            Reinforce statistics               Charts, graphs,
                                                   animated numbers

CONTEXT         Establish setting/relevance        Office environment,
                                                   related industry

REACTION        Human element/emotion              Stock footage of
                                                   people reacting
```

### B-Roll Planning Workflow

1. **During Scriptwriting:** Note visuals beside each point
2. **Pre-Production:** List all B-roll needed, prioritize
3. **Source Strategy:**
   - Self-shoot demonstration footage
   - Screen capture for digital processes
   - Stock libraries (Pexels, Pixabay, Envato, Artgrid)
   - AI-generated imagery for concepts

### B-Roll Quality Checklist
- [ ] Every shot has a purpose (not decorative)
- [ ] Matches content being discussed
- [ ] Consistent style across video
- [ ] Movement flows naturally (show motion as it happens)
- [ ] High quality (no pixelation or blur)

## PART 3: TYPOGRAPHY & TEXT ON SCREEN

### Font Selection

**For Headlines/Emphasis:**
- Bold sans-serif (Montserrat, Bebas Neue, Impact)
- High legibility at all sizes
- Strong personality that matches brand

**For Body/Explanatory Text:**
- Clean sans-serif (Inter, Open Sans, Roboto)
- Easy to read quickly
- Neutral, not distracting

### Size Guidelines

```
ELEMENT                 SIZE RANGE           SCREEN TIME
──────────────────────────────────────────────────────────
Headlines/Key Points    100-200px            3-4 seconds
Subheadings            60-80px              2-3 seconds
Body Text              40-50px              4-5 seconds
Lower Thirds (Names)   30-40px              2-4 seconds
Captions               30-40px              Matched to speech
```

### Text Placement Rules

1. **Title Safe Zone:** Keep text within center 80% of frame
2. **Lower Thirds:** Bottom-left for names, titles
3. **Headlines:** Top-center or center-left
4. **Never compete with face** in talking head shots
5. **Avoid YouTube UI areas:** Skip, subscribe button zones

### Text Animation Best Practices

- **Entrance:** Fade, slide, or pop (0.2-0.3 seconds)
- **Hold:** Long enough to read 2x (assume slow readers)
- **Exit:** Same style as entrance, or cut with scene change
- **Easing:** Use ease-out for natural motion

### Color and Contrast

- **Text:** White or light gray on dark backgrounds
- **Backgrounds:** Solid or semi-transparent boxes for readability
- **Brand Colors:** Use sparingly for emphasis
- **Test:** Squint at screen—if unreadable, increase contrast

## PART 4: MOTION GRAPHICS

### Essential Templates to Create

1. **Intro Animation** (3-5 seconds max)
   - Logo reveal, channel name, tone-setter
   - NOT required—can skip for faster engagement

2. **Lower Third Template**
   - Name and title for speakers
   - Consistent placement and style

3. **Transition Package**
   - 2-3 consistent transitions for scene changes
   - Avoid overuse—cuts are underrated

4. **Callout/Pointer Graphics**
   - Arrows, circles, highlights
   - Use to direct attention on screen

5. **Numbered Steps Animation**
   - "Step 1", "Step 2" reveals
   - For process/tutorial content

6. **Subscribe CTA Animation**
   - Subtle, appears at strategic moments
   - NOT in first 50% of video

### Motion Principles

```
PRINCIPLE          DESCRIPTION                        APPLICATION
────────────────────────────────────────────────────────────────
Easing             Never linear motion               Ease-out for enters,
                                                     ease-in for exits

Consistency        Same timing rules everywhere      All text animates
                                                     at same speed

Purpose            Motion draws attention            Only animate what
                                                     matters

Subtlety           Micro-animations > flashy         Small movements
                                                     feel premium
```

### Animation Timing

- **Fast Transitions:** 0.1-0.3 seconds
- **Text Reveals:** 0.3-0.5 seconds
- **Callout Animations:** 0.2-0.4 seconds
- **Scene Transitions:** 0.3-0.6 seconds

## PART 5: LIGHTING SETUP

### Three-Point Lighting (Standard Setup)

```
                    [BACKLIGHT]
                         |
                         |
                    [SUBJECT]
                    /         \
                   /           \
           [KEY LIGHT]    [FILL LIGHT]
            (45° left)     (45° right)
            (above)        (dimmer)
```

**Key Light:**
- Main light source, 45° angle from subject
- Slightly above eye level
- Creates primary illumination

**Fill Light:**
- Opposite side from key, lower intensity (50-75%)
- Softens shadows created by key
- Prevents harsh, dramatic look

**Backlight/Rim Light:**
- Behind and above subject
- Separates subject from background
- Creates depth and professional look

### Natural Light Alternative

- Position subject facing window
- Window = key light
- Reflector on opposite side = fill (white foam board works)
- NEVER put window behind subject (creates silhouette)

### Lighting Quality Checklist

- [ ] No harsh shadows under eyes or nose
- [ ] Face evenly lit (check both sides)
- [ ] Subject separated from background
- [ ] No glare on glasses (adjust key light angle)
- [ ] Color temperature consistent (all lights same color)
- [ ] Background has some light, not pure black

## PART 6: VISUAL RHYTHM & PACING

### The 5-Second Rule
**Add visual interest every 5 seconds in educational content:**
- B-roll cutaway
- Text overlay
- Zoom in/out
- Camera angle change
- Graphic element

### Pacing by Segment

```
SEGMENT           PACING                    VISUAL ACTIVITY
────────────────────────────────────────────────────────────────
Hook (0-15s)      FAST                      Quick cuts, high energy,
                                            immediate visual impact

Concept           MEDIUM                    Diagrams, text overlays,
(30-120s)                                   steady rhythm

Example           MEDIUM-SLOW               Demonstration B-roll,
(120-180s)                                  screen capture, proof

Application       MEDIUM                    Numbered steps,
(180-300s)                                  checklists, graphics

CTA (end)         SLOW                      Clean frame, subscribe
                                            animation, end screen
```

### Pattern Interrupts (Visual)

Place at predicted drop-off points (2-4 min, 5+ min marks):

- **Quick scene change** (new background/angle)
- **Music shift** (energy increase)
- **Animation burst** (unexpected motion)
- **Color/lighting change** (mood shift)
- **New speaker or perspective**

## PART 7: NOTEBOOKLM-SPECIFIC VISUAL SETTINGS

### Video Formats

**Explainer:** Structured, comprehensive (6-10+ minutes)
- Use for: Deep-dive content, tutorials, frameworks

**Brief:** Concise, bite-sized (1-3 minutes)
- Use for: Quick tips, summaries, teasers

### Visual Styles Available

```
STYLE           VIBE                      BEST FOR
─────────────────────────────────────────────────────
Classic         Professional, clean       Business, corporate
Whiteboard      Diagrams, hand-drawn      Explainer, education
Watercolor      Soft, artistic            Personal, creative
Retro Print     Vintage, textured         Storytelling, media
Heritage        Traditional, classic      Historical, cultural
Paper-craft     Tactile, crafty           DIY, hands-on topics
Kawaii          Cute, colorful            Younger audience, fun
Anime           Animated, dynamic         Tech, gaming, youth
```

### Custom Visual Style Prompts

**For Professional/Business:**
```
"Business style with minimalist design. Blue and gray palette.
Clean sans-serif typography. Modern, sleek aesthetic with
subtle gradient backgrounds."
```

**For Educational:**
```
"Classroom style with warm colors. Chalkboard and book imagery.
Friendly, approachable aesthetic. Clear diagrams with soft
shadows and rounded corners."
```

**For Tech/AI:**
```
"Futuristic tech style with dark backgrounds. Neon accent colors
(cyan, magenta). Circuit board patterns. Holographic elements.
Modern, cutting-edge aesthetic."
```

### Steering Prompts for NotebookLM

Include in your steering prompt:
- **Target audience** (experience level, industry)
- **Tone** (energetic, measured, professional)
- **Key concepts** to emphasize
- **Visual focus** (diagrams, quotes, data)

**Example:**
```
"Focus on making this educational and visually engaging.
Target audience is business executives with limited AI knowledge.
Emphasize the practical frameworks with visual diagrams.
Use a professional but accessible tone.
Pull statistics and quotes from the source material for
visual emphasis."
```

## PART 8: COLOR PALETTE FOR EDUCATIONAL CONTENT

### Recommended Palettes

**Professional/Corporate:**
```
Primary:   #1E3A5F (Navy)
Secondary: #4A7C59 (Forest)
Accent:    #E07A5F (Coral)
Neutral:   #F2F2F2 (Light Gray)
```

**Tech/AI:**
```
Primary:   #0D1B2A (Dark Navy)
Secondary: #1B4965 (Slate Blue)
Accent:    #62B6CB (Cyan)
Warning:   #F4A261 (Orange)
```

**Warm/Educational:**
```
Primary:   #2C3E50 (Charcoal)
Secondary: #E67E22 (Orange)
Accent:    #3498DB (Sky Blue)
Neutral:   #ECF0F1 (Off-White)
```

### Color Usage Rules

1. **Primary:** Background elements, headers
2. **Secondary:** Supporting graphics, callouts
3. **Accent:** Emphasis, CTAs, important numbers
4. **Neutral:** Text backgrounds, breathing space

## PART 9: VISUAL PRODUCTION CHECKLIST

### Pre-Production
- [ ] Thumbnail concept designed
- [ ] B-roll shot list from script
- [ ] Graphics/templates prepared
- [ ] Color palette defined
- [ ] Fonts selected and sourced

### Production
- [ ] Lighting setup verified
- [ ] Audio levels checked
- [ ] Multiple angles captured (if applicable)
- [ ] B-roll footage captured/sourced

### Post-Production
- [ ] Visual variety every 5-10 seconds
- [ ] Text on screen readable and timed correctly
- [ ] Transitions consistent throughout
- [ ] Color correction applied uniformly
- [ ] Motion graphics smooth and purposeful
- [ ] Thumbnail created and A/B tested

### Final Review
- [ ] Watch on mobile (small screen test)
- [ ] Watch with sound off (visual clarity test)
- [ ] Check thumbnail at 1-inch size
- [ ] Verify no YouTube UI conflicts

```
0:00-0:15 (HOOK)
├─ Bold, attention-grabbing visuals
├─ Quick cuts or movement
├─ Visual promise of value
└─ Title/topic immediately clear

0:15-0:30 (CREDIBILITY)
├─ Lower third with name/title
├─ Professional framing
└─ Subtle brand elements

0:30-2:00 (CONCEPT)
├─ Diagrams/frameworks introduced
├─ Key terms on screen
├─ Analogy visualized with B-roll
└─ Visual change every 10s minimum

2:00-4:00 (EXAMPLE)
├─ Demonstration B-roll heavy
├─ Screen capture for digital
├─ Data/statistics visualized
└─ Proof elements (screenshots, results)

4:00-5:00 (APPLICATION)
├─ Step-by-step numbered graphics
├─ Checklists/bullet points on screen
├─ Clean, uncluttered frames
└─ Practical, actionable visuals

5:00-5:30 (BONUS)
├─ "Secret" reveal moment
├─ Emphasis graphics/callouts
└─ High-value visual element

5:30-6:00 (CTA + OUTRO)

```
